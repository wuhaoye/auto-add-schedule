# 截图模块

## 目标

- 全局快捷键唤起后，在所有显示器上显示暗色遮罩，鼠标拖选矩形区域。
- 选区下方（空间不足时上方）显示工具条：确定 / 放弃 / 重选 / 补充信息；Enter 确定、Esc 放弃。
- 覆盖 Windows 高 DPI 与多显示器场景，输出裁剪后的位图（物理像素）供保存与大模型识别。

## 实现要点

- 使用 Win32 GDI BitBlt 抓取屏幕，按显示器分别抓取，避免 DPI 缩放错位。
- 遮罩窗口使用 WindowStyle=None、Topmost、AllowsTransparency，每个显示器一个窗口，各自按该显示器 DPI 换算坐标。
- 选区坐标最终换算回物理像素，从原始截图中裁剪。
- 工具条为自绘 WPF 控件，深色半透明背景。
- 补充信息对话框为普通 WPF 窗口，输入内容随本次截图返回。
