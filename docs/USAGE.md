# 使用说明

## 启动

双击 AutoAddSchedule.exe。程序常驻系统托盘（右下角通知区域），主窗口可关闭而不退出。

## 截图添加日程

1. 按 Ctrl+Alt+\（或托盘菜单「截图添加日程」）。
2. 屏幕变暗，按住鼠标左键拖动框选通知/聊天记录中与日程相关的区域。
3. 松开鼠标后，选区下方出现工具条：
   - 确定：提取并把日程同步到 iCloud（也可按 Enter）
   - 放弃：取消本次截图（也可按 Esc）
   - 重选：清除当前选区重新框选
   - 补充信息：输入额外说明（例如「提前30分钟提醒我」「地点在图书馆」），会随图片一起发给大模型
4. 完成后托盘弹出结果通知。

截图会自动保存到程序目录 screenshots\，默认保留最近 60 张，超出自动删除最旧的。

## 手动添加日程

主界面「日程」页点击「新增」：填写标题、开始时间、结束时间、地点、描述、提前提醒分钟数，
保存后联网时自动同步到 iCloud（不经过大模型）。

## 主界面

- 日历：月视图，显示每天的日程数量，点击日期查看当天日程。
- 日程：列表显示全部日程，支持新增、编辑、删除、手动刷新同步。
- 设置：大模型、iCloud 日历、快捷键、通用选项。

## 提醒

程序常驻时，会按日程的「提前量」通过托盘气泡提醒。提醒触发时间 = 日程开始时间 − 提前分钟数。
系统时间或日程修改后，提醒会重新计算。
